beautyPOS を、自分のパソコンで動かしてみよう

beautyPOS は、美容品販売店のレジ業務（商品検索・カート・会計・在庫更新）を再現した練習用アプリです。 このページでは、プログラミングの知識が無くても迷わないように、パソコンに何もインストールされていない状態から 「ブラウザでレジ画面が開いて、実際に会計できる」ところまでを順番に進めます。

Java 21 Spring Boot PostgreSQL Thymeleaf Gradle
①準備→ ②確認→ ③入手→ ④DB準備→ ⑤ビルド→ ⑥起動→ ⑦動作確認→ ⑧保存
1
準備するもの

パソコンに必要な道具をそろえる

beautyPOS は「Java」というプログラミング言語で書かれています。動かすには、次の4つの道具が必要です。 難しく感じるかもしれませんが、それぞれ一度インストールすれば準備は完了です。

  • Java 21 — プログラムを実際に動かすための土台（エンジン）
  • Git — ソースコード（プログラムの中身）を取得・保存するための道具
  • PostgreSQL — 商品や売上のデータをしまっておくデータベース
  • VS Code — コードを見たり編集したりするためのアプリ（任意）

WHY Windowsには最初から入っていないため、この4つは自分で用意する必要があります。

PowerShellを開いて、上から順に1行ずつ実行
> winget install EclipseAdoptium.Temurin.21.JDK
> winget install Git.Git
> winget install PostgreSQL.PostgreSQL
> winget install Microsoft.VisualStudioCode
✓
できたか確認PostgreSQLのインストール中に「postgresユーザーのパスワード」を聞かれます。ここで決めたパスワードは後で使うので必ずメモしておきましょう。インストーラーが終わったら、一度PowerShellのウィンドウを閉じて開き直してください（インストール直後は反映されていないことがあります）。
2
インストール確認

4つの道具が正しく入ったか確認する

インストールできたつもりでも、実は失敗していることがあります。次のコマンドで、 それぞれのバージョン番号が表示されるかを確認しましょう。ここで確認しておくと、後の工程でのエラーの原因を切り分けやすくなります。

PowerShellで1つずつ実行
> java -version
openjdk version "21.0.x" ... のように表示されればOK

> git --version
git version 2.x.x のように表示されればOK

> psql --version
psql (PostgreSQL) 18.x のように表示されればOK

> code --version
バージョン番号が3行表示されればOK
✓
できたか確認4つとも「コマンドが見つかりません」にならず、バージョン番号が表示されればStep1は完了です。もし見つからない場合は、パソコンを一度再起動してから、もう一度試してください。
3
プロジェクトの入手

プログラムの中身を自分のパソコンにコピーする

beautyPOS のソースコードは GitHub というサービスに保管されています。 「clone（クローン）」というコマンドで、まるごと自分のパソコンにコピーします。

コピー先にしたいフォルダ（例：ドキュメント）で実行
> git clone https://github.com/maythazinoo12mm/beautyPOS.git
> cd beautyPOS
✓
できたか確認beautyPOS という名前のフォルダができていて、中に build.gradle や src フォルダがあればOKです。

次に ここから先の作業は、コマンドを直接打つ代わりにVS Codeを使うと見通しが良くなります。

VS Codeでプロジェクトを開く（同じ場所で実行）
> code .
  1. VS Codeが起動し、左側にbeautyPOSのフォルダ構成が表示される
  2. 初回は右下に拡張機能のおすすめが出るので「Extension Pack for Java」と「Spring Boot Extension Pack」をインストールする（無くても動くが、コード補完やボタン一つでの起動ができて便利）
✓
できたか確認VS Code左側のエクスプローラーに src・docs・build.gradle などが見えていればインポート完了です。
4
データの保管場所

データベースを準備する

商品情報や売上履歴を保存しておく「データベース」と、それを使うための「専用の鍵（ユーザー）」を1回だけ作ります。

WHY 誰でもアクセスできると困るので、beautyPOS専用のデータベースと、それ専用のユーザーを分けて作ります。
Windowsのスタートメニューから「SQL Shell (psql)」を開き、そのまま実行
-- Enterを押していくとユーザー名やパスワードを聞かれます
-- パスワードはStep1でメモした「postgresユーザーのパスワード」を入力

CREATE DATABASE beautypos;
CREATE USER beautypos_user WITH PASSWORD 'beautypos_pass';
GRANT ALL PRIVILEGES ON DATABASE beautypos TO beautypos_user;
✓
できたか確認それぞれ実行後に CREATE DATABASE や CREATE ROLE と表示されればOKです。beautyPOS側の接続設定（ユーザー名・パスワード）は、あらかじめこの値に合わせて用意されているので、追加の設定は不要です。
5
組み立て

プログラムをビルド（組み立て）する

「ビルド」とは、書かれたソースコードをパソコンが実行できる形に組み立てる作業のことです。 ここで文法ミスなどがあればエラーとして教えてくれます。

beautyPOSフォルダの中で実行
> .\gradlew.bat build
✓
できたか確認最後に BUILD SUCCESSFUL と表示されればOKです。初回は関連ファイルのダウンロードが入るため、数分かかることがあります。
6
起動

アプリを起動する

いよいよ起動です。実行すると、パソコンの中に小さなWebサーバーが立ち上がり、 ブラウザからアクセスできるようになります。起動したままにしておく必要があるので、 このウィンドウは閉じずに残しておきましょう。

beautyPOSフォルダの中で実行
> .\gradlew.bat bootRun
✓
できたか確認ログの最後の方に Started SpringBootPracticeApplication と表示されれば起動成功です。このとき裏側では、データベースに商品テーブルや初期商品データが自動的に作られています。
7
動作確認

ブラウザで実際に触ってみる

起動したままの状態で、ブラウザを開いて動作を確認しましょう。

  1. http://localhost:8080/ を開く → レジ画面が表示される
  2. テキスト欄に C001 と入力して「カートに追加」を押す → 「化粧水」がカートに入る
  3. 「会計へ進む」→ お預かり金額に 2000 と入力 → お釣りが自動で表示される
  4. 「支払い確定」を押す → 会計完了画面が表示される
✓
できたか確認会計完了画面が表示され、/items（商品管理）で化粧水の在庫が1つ減っていれば、データベースへの保存まで含めて全て正常に動いています。🎉
8
おまけ・任意

自分で変更を加えたら、GitHubに保存する

コードを書き換えたりドキュメントを更新したりしたら、GitHubに保存（push）しておくと、 他のパソコンからも取り出せますし、変更の履歴も残ります。

変更を加えた後、beautyPOSフォルダの中で実行
> git add .
> git commit -m "変更内容の説明"
> git push
✓
できたか確認github.com/maythazinoo12mm/beautyPOS を開いて、最新のコミットが反映されていればOKです。
✓

ここまでで、beautyPOSが動く状態になりました

お疲れさまでした。あとは自由に触って、レジ・商品管理・売上履歴の画面を見比べてみてください。

次にやること

他の画面も見てみる

/items で商品管理、/sales で売上履歴が見られます。

テストの実行

自動テストを試す

.\gradlew.bat test で、データベース不要のテストが一通り実行できます。

もっと知る

ドキュメントを読む

docs フォルダに、業務フローやDB構成、テスト結果がまとまっています。

うまくいかないときは

「ポート8080は使用中です」と出て起動しない

すでに beautyPOS が別のウィンドウで起動したままになっている可能性があります。そのウィンドウを探して Ctrl+C で一度止めてから、もう一度 .\gradlew.bat bootRun を実行してください。

データベースに接続できないというエラーが出る

PostgreSQLが起動しているか確認してください。またStep3で作った「beautypos_user」というユーザー名と「beautypos_pass」というパスワードが、他の作業で変更されていないかも確認しましょう。

winget コマンドが見つからないと言われる

Windows 10/11であれば通常はじめから使えますが、古いバージョンの場合は Microsoft Store から「アプリ インストーラー」を更新すると使えるようになります。

結局どのフォルダで、どのコマンドを打てばいいか分からなくなった

このガイドのコマンドは、Step2でできた beautyPOS フォルダの中で実行するものがほとんどです。エクスプローラーでそのフォルダを開き、アドレスバーに powershell と入力してEnterを押すと、そのフォルダを開いた状態でPowerShellが立ち上がります。
